# Проект: продуктовая аналитика маркетплейса

Комплексный продуктовый аудит маркетплейса —
от верхнеуровневых метрик до юнит-экономики, сегментации и A/B-эксперимента
с рекомендацией для бизнеса.

## Описание проекта

Анализ выполнен в пять этапов:

1. **Предобработка данных** — загрузка четырёх таблиц, фильтрация лишнего периода
   (январь 2025), проверка дубликатов и типов данных.
2. **Обзор ключевых метрик** — динамика Revenue, ARPAU, ARPPU, WAU/MAU, AOV
   и конверсии из активных пользователей в платящих (по неделям и месяцам,
   со скользящими средними).
3. **Юнит-экономика** — CAC по каналам и когортный анализ: LTV по месяцам жизни
   когорт, ROI, период окупаемости. Выручка маркетплейса — 5% комиссии с продажи.
4. **Сегментация и воронки** — разрезы по сегментам покупателей, каналам
   привлечения, категориям, устройствам, ОС, возрасту, полу и регионам; воронки
   конверсии в целом и по срезам. По итогам сформулированы продуктовые гипотезы.
5. **A/B-эксперимент** — по итогам гипотез бизнес внедрил бонус на первую покупку
   для пользователей из TikTok. Проведён дизайн эксперимента (основная, барьерная
   и вспомогательные метрики), проверка качества сплита, Z-тест основной метрики,
   t-тесты вспомогательных, итоговая бизнес-рекомендация.

## Данные

Датасеты предоставлены Яндекс Практикумом и загружаются в ноутбуке напрямую
по публичным ссылкам — репозиторий полностью воспроизводим:

- `pa_marketplace_orders.csv` — заказы;
- `pa_marketplace_users.csv` — пользователи и когорты;
- `pa_marketplace_events.csv` — события;
- `pa_marketplace_campaign_costs.csv` — маркетинговые расходы;
- `pa_diploma_*_AB.csv` — данные эксперимента (события, заказы, сессии,
  пользователи, сплит по группам).

## Как запустить

1. Открыть ноутбук в Jupyter или Google Colab;
2. Выполнить все ячейки (Run all) — данные подтянутся автоматически.

Требования: Python 3, pandas, numpy, matplotlib, seaborn, scipy, statsmodels.

## Структура проекта

## Ключевые результаты

- **Выручка** за год — около 22 млн, но рост неустойчив: с сентября выручка,
  ARPAU и ARPU последовательно падают, ожидаемого сезонного пика
  (Чёрная пятница, Новый год) нет.
- **Конверсия в покупку** — главная точка падения: с ~40% до 24% по месяцам
  и менее 20% по неделям. Аудитория и средний чек при этом держатся.
- **Юнит-экономика**: при среднем CAC 437,75 и месячном ARPU 41,52 привлечение
  окупается примерно за 10,5 месяца; когорты второй половины года не выходят
  в положительный ROI — масштабировать маркетинг без роста конверсии убыточно.
- **A/B-эксперимент (бонус на первую покупку, TikTok)**: рост конверсии
  статистически значим (Z-тест, p < 0.05), рост ARPU значим, ARPPU и AOV —
  без значимого эффекта. Рекомендация: поэтапное внедрение бонуса с мониторингом
  долгосрочного эффекта и unit-экономики.
