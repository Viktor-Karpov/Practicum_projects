# Портфолио аналитика данных — Виктор Карпов

Полный цикл аналитики — от статистических
проверок гипотез до построения ETL-пайплайнов.

## Стек

Python (pandas, numpy, scipy, statsmodels, matplotlib, seaborn),
PySpark, SQL (ClickHouse), Airflow, A/B-тестирование, когортный анализ,
юнит-экономика.

## Проекты

### 1. Gродуктовая аналитика маркетплейса

Полный цикл продуктовой аналитики — от
предобработки данных до проверки гипотез.

- Обзор ключевых метрик: Revenue, ARPU/ARPPU, WAU/MAU, AOV, конверсия;
- Юнит-экономика: когортный анализ, LTV, CAC, ROI, период окупаемости;
- Сегментация по каналам привлечения, сегментам покупателей, устройствам,
  анализ воронки;
- A/B-эксперимент: проверка гипотез и расчёт мощности выборки.

Ключевые результаты: выручка 22 млн ₽, выявлено падение конверсии 40% → 24%,
CAC 437,75 ₽ при окупаемости ~10,5 месяца.

### 2. A/B-тест: аудит результатов и проверка гипотез

Статистический анализ данных сервиса Яндекс Книги в двух частях.

- t-тест: сравнение времени чтения пользователей Москвы и Санкт-Петербурга —
  различий не выявлено (p-value ≈ 0.34);
- Аудит A/B-теста новой платёжной воронки: проверка корректности разбиения
  групп, Z-тест для долей — рост конверсии статистически значим, механику
  можно выкатывать на всех пользователей.

### 3. ETL-пайплайн: витрина данных Яндекс Такси

Автоматизированный ETL-пайплайн.

- DAG в Airflow с ежедневным расписанием: S3KeySensor дожидается появления
  файла с данными и запускает Spark-задачу на кластере DataProc;
- PySpark-скрипт агрегирует поездки по способам оплаты и через JDBC записывает
  витрину в ClickHouse.

## Воспроизводимость

- Проекты 1 и 2 загружают данные по публичным ссылкам Яндекс Практикума —
  воспроизводятся запуском ноутбука в Google Colab;
- Проект 3 исполняется на учебной инфраструктуре Яндекс Облака
  (DataProc, ClickHouse, Airflow), вне неё не запускается — в репозитории
  зафиксированы код и архитектура пайплайна.
